prose

Scope: user-facing copy, error strings, commit messages, PR bodies, and agent replies about this repo.

Language
- American English: color, recognize, center.
- Plain language over jargon. Define a rare term once, then reuse it.
- No Unicode em-dash (U+2014). Use colon, comma, period, or and/or/but instead.

Errors
- State what is wrong, where it happened, and what to do next.
- Assume the reader knows nothing about internals.
- Keep errors well-typed; do not leak stack traces to end users in production paths.

Attribution
- No attribution footers on commits, PRs, issues, or source files.
- No "Generated by" or model credit lines in repo artifacts.

Communication
- Lead with the finding or change, then mechanism and rejected options only when they change a decision.
- One fact once. Do not restate the same constraint in closing sentences.
- Prefer positive statements over double negatives.

Docs in this repo
- Agent standards live under agent-docs/. Never author in docs/ (generated GitHub Pages output).
- Research notes belong in research/, not in standards files.
- Do not copy long passages from AGENTS.md into other files; point to the home fact instead.

Quotes
- Reproduce quoted material exactly, including its original punctuation.
- Em-dashes inside a verbatim quote are allowed; do not add new em-dashes outside quotes.
